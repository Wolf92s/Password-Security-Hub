Password Security Hub
I created this website because I've seen all these technologies coming out but they still have a simple flaw. They still require a password on the account. Password managers make it easy to make a strong password for every site but you need a strong password for that password manager. This is where the generator page comes it. 

One password, pick what you want on the encryption method or leave it default. Choose the length and what characters you want to include. To get the password you should only have to agree to the terms once, this uses LocalStorage to save to avoid needing to agree every time.

This site doesn't need anything to be used offline. Just download all the files and you are good to go (images aren't fully needed for it to run properly).
